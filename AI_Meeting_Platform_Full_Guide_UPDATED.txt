AI MEETING MINUTES PLATFORM - FULL PROJECT OVERVIEW (UPDATED)

------------------------------------------------------------
1. PROJECT VISION
------------------------------------------------------------
The AI Meeting Minutes Platform is designed to automatically capture,
transcribe, analyze, and generate structured Minutes of Meeting (MoM)
from live physical or online meetings.

Goal:
- Replace manual note-taking
- Provide real-time live captions
- Generate structured, accurate meeting minutes
- Support multilingual and multi-speaker environments
- Learn recurring speakers and meeting context over time
- Improve accuracy through voice training, context AI, and stronger noise suppression

------------------------------------------------------------
2. SYSTEM ARCHITECTURE OVERVIEW
------------------------------------------------------------
The system consists of 6 main layers:

1. Frontend (React)
   - Live meeting UI
   - Microphone streaming
   - Real-time transcript display
   - Live MoM panel

2. Backend (FastAPI)
   - WebSocket live streaming engine
   - Chunk processing pipeline
   - Transcript storage (MongoDB)
   - Minutes generation
   - Meeting-state and review workflow

3. ASR Layer
   - TorongoXetu Assamese model
   - NeMo-based inference
   - HTTP bridge service

4. AI Processing Layer
   - Gemini (for MoM generation)
   - Cleanup & normalization pipeline
   - Future context-aware correction layer

5. Voice Intelligence Layer (Planned)
   - Speaker profile enrollment
   - Voice training / speaker adaptation
   - Speaker identification and diarization

6. Audio Quality Layer
   - Browser-level noise suppression
   - Backend chunk filtering
   - Future advanced noise suppression / speech enhancement

------------------------------------------------------------
3. WORKFLOW (END-TO-END)
------------------------------------------------------------
Step 1: User starts meeting from frontend

Step 2: Microphone stream starts
- Audio captured
- Browser audio constraints applied
- VAD (Voice Activity Detection) filters some noise

Step 3: Audio chunks sent to backend via WebSocket

Step 4: Backend processes chunks
- Buffering
- Overlap handling
- WAV conversion

Step 5: Sent to TorongoXetu bridge
- Assamese transcription

Step 6: Transcript cleanup
- Remove fillers
- Normalize text
- Fix punctuation
- Deduplicate overlap errors

Step 7: Live UI updates
- transcript.partial (real-time)
- transcript.final (clean segments)

Step 8: Data stored in MongoDB

Step 9: Live Minutes generated periodically

Step 10: On meeting end
- Final transcript compiled
- AI generates structured MoM
- Data saved + displayed

Future extended workflow:
- Voice-trained speaker profiles improve identification
- Context AI improves domain vocabulary and sentence correction
- Enhanced noise suppression reduces background voices/noise
